# Part 4 - AI Solution Design for a Business Problem

## Project Overview

This project presents an AI-based healthcare solution for early sepsis risk prediction using patient clinical data.

The project focuses on:
- Business problem formulation
- AI task identification
- Data requirement planning
- Model recommendation
- Evaluation strategy
- Responsible AI considerations

---

# Selected Business Domain

Healthcare

---

# Business Problem

Hospitals often face delays in identifying sepsis in admitted patients.

Delayed detection may lead to:
- Organ failure
- Increased ICU admissions
- Higher mortality rates
- Increased treatment cost

The proposed AI system predicts sepsis risk early using patient vitals, laboratory reports, and clinical history.

---

# Proposed AI Solution

An LSTM-based sequence prediction model analyzes patient health records over time and predicts the likelihood of sepsis development.

---

# AI Task Type

Sequence Prediction + Classification

---

# Model Recommendation

- LSTM Neural Network
- Transformer-based extension for future scalability
